【基础信息】
- 政策标题：商品破损补发处理规范
- 生效日期：2026-01-20
- 失效日期：-
- 适用商品分类：全品类

1. 适用范围
1.1 签收时发现运输导致的商品破损、配件破损
1.2 开箱后发现原厂包装内配件破损、缺失
1.3 非人为损坏的商品外观/部件破损

2. 举证要求
2.1 签收后48小时内提交申请
2.2 提供破损部位清晰照片、整体包装照片、快递面单照片
2.3 配件缺失需提供开箱完整视频

3. 处理方式
3.1 仅配件破损：补发对应配件
3.2 主体破损但可维修：提供维修服务或补发部件
3.3 主体严重破损无法使用：补发全新商品，或全额退款
3.4 消费者同意保留破损商品的，给予对应比例差价退款

4. 补发时效
4.1 审核通过后24小时内安排补发
4.2 补发物流时效同正常发货标准
4.3 补发产生的运费由商家承担

5. 不予补发情形
5.1 人为摔碰、使用不当造成的破损
5.2 超出48小时举证时效
5.3 无法提供有效举证材料
5.4 已自行拆卸、改装的商品

6. 常见问题
Q：补发的商品和原来的是一样的吗？
A：是的，补发同款同规格全新商品/配件。

Q：可以直接退款不补发吗？
A：可以，您可以在申请时选择退款方式。
