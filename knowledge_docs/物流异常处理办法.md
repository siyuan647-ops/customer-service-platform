【基础信息】
- 政策标题：物流异常处理办法
- 生效日期：2026-03-01
- 失效日期：-
- 适用商品分类：全品类

1. 物流延迟
1.1 超出承诺配送时效仍未更新物流信息，视为物流延迟
1.2 处理方式：
    - 消费者可联系客服催促物流、核实情况
    - 延迟超过3天，可申请全额退款或重新发货
    - 生鲜商品延迟导致变质，全额退款

2. 物流丢件
2.1 物流信息超过7天无更新，或快递公司确认丢件，视为丢件
2.2 处理方式：
    - 消费者可选择全额退款，或重新安排发货
    - 丢件责任由商家承担，无需消费者承担费用

3. 运输破损
3.1 运输途中导致商品破损、漏液、变形
3.2 处理方式：
    - 当场拒收，退回后退款或重发
    - 已签收的，48小时内举证，可申请补发、部分退款或全额退款

4. 错发/漏发
4.1 商品、规格、数量与订单不符
4.2 处理方式：
    - 错发：消费者退回错发商品，商家承担运费并补发正确商品，或直接退款
    - 漏发：补发缺少商品，或退还对应部分货款

5. 处理时效
5.1 客服接到反馈后24小时内核实物流情况
5.2 核实确认后，48小时内执行退款或补发

6. 常见问题
Q：物流一直不动，我可以退款吗？
A：超出承诺时效3天以上，可以申请全额退款，无需退回商品。

Q：丢件了我需要提供什么证明吗？
A：无需您举证，我们会和快递公司核实，确认后直接为您处理。
