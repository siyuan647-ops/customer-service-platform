- 政策标题：商品签收与拒收规则
- 生效日期：2026-02-10
- 失效日期：-
- 适用商品分类：全品类

1. 签收规范
1.1 请在签收前当场验货，检查包装是否完好、商品是否破损、数量是否相符
1.2 代收点、驿站代收的，请在取件时当场核验
1.3 签字签收视为确认商品外观、数量无误

2. 正常拒收条件
2.1 商品包装严重破损、变形、漏液
2.2 商品与订单不符、缺少配件
2.3 商品明显损坏、变质
2.4 未经同意私自代签，且消费者未收到商品

3. 不予拒收情形
3.1 商品外包装轻微挤压，内物完好
3.2 消费者个人原因不想要、拍错、多拍
3.3 生鲜食品因消费者原因延迟收货导致变质
3.4 已经签收后再提出拒收

4. 拒收流程
4.1 当场向快递员说明拒收原因，拍照留证
4.2 快递员退回商品后，商家验收无误，为您办理退款或重发
4.3 个人原因拒收，需承担往返运费

5. 签收后异常处理
5.1 签收后发现内部破损、质量问题，按《质量问题退款处理规范》执行
5.2 签收后发现少件、错发，24小时内联系客服举证处理

6. 常见问题
Q：快递直接放驿站了，我没验货怎么办？
A：取件时当场验货，有问题2小时内联系客服并提供照片，我们会协助处理。
