【基础信息】
- 政策标题：七天无理由退货规则
- 生效日期：2026-01-01
- 失效日期：-
- 适用商品分类：全品类（特殊商品除外，见例外规则）

1. 政策概述
消费者在签收商品后七日内，因个人意愿不愿保留商品，在商品保持完好且不影响二次销售的前提下，可申请无理由退货退款。

2. 适用条件
2.1 商品签收次日零时起计算，7×24小时内提交退货申请
2.2 商品主体、配件、吊牌、包装完整，无磨损、污渍、划痕
2.3 一次性密封包装商品未拆封，数码电子产品未激活
2.4 赠品、发票需一并退回

3. 不适用情形
3.1 消费者定制类商品
3.2 鲜活易腐类商品（水果、生鲜、冷藏食品等）
3.3 在线下载或消费者拆封的音像制品、数字商品、虚拟卡券
3.4 贴身用品（内衣、袜子、泳装、成人用品等）
3.5 拆封后易导致人身安全或健康风险的商品
3.6 拍卖类、二手闲置类商品

4. 办理流程
4.1 订单详情页提交“七天无理由退货”申请，选择退货原因
4.2 商家24小时内审核，审核通过后提供退货地址
4.3 消费者72小时内寄出商品，填写物流单号
4.4 商家签收商品后48小时内核验，核验通过后发起退款
4.5 退款原路返回，到账时效1-7个工作日，以支付渠道规则为准

5. 运费承担规则
5.1 七天无理由退货，返程运费由消费者承担
5.2 订单含运费险的，退货完成后运费险自动理赔，理赔金额以保单为准
5.3 商家发错货、商品质量问题导致的退货，不适用本规则，按质量问题退款处理

6. 常见问题
Q：签收当天算第一天吗？
A：不算，自签收次日零时开始计算7天。

Q：已经拆了包装还能退吗？
A：外包装拆封但内件完好、吊牌保留、不影响二次销售的普通商品可以；一次性密封包装、激活类数码产品拆封后不支持。

Q：退款退到哪里？多久到账？
A：原路退回支付账户，微信/支付宝一般1-3个工作日，银行卡3-7个工作日。
