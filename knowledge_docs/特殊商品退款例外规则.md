【基础信息】
- 政策标题：特殊商品退款例外规则
- 生效日期：2026-02-01
- 失效日期：-
- 适用商品分类：生鲜食品、定制商品、虚拟商品、贴身用品

1. 生鲜食品类
1.1 生鲜商品不支持七天无理由退货
1.2 签收时发现变质、破损、缺斤少两，当场拒收或2小时内举证，可申请退款或补发
1.3 因消费者原因延迟签收、保存不当导致变质，不予退款

2. 定制商品类
2.1 含个性化印字、定制尺寸、专属图案的定制商品，不支持七天无理由退货
2.2 商家制作错误、与约定不符，可申请重做或全额退款
2.3 消费者中途取消订单，需承担已产生的制作成本

3. 虚拟商品类
3.1 话费、流量、游戏充值、会员卡券等虚拟商品，充值成功后不支持退款
3.2 未充值成功、充值账号错误，可申请更正或退款
3.3 电子卡券已核销的不予退款

4. 贴身用品类
4.1 内衣、内裤、袜子、泳装、口罩、成人用品等贴身商品，拆封后不支持七天无理由退货
4.2 存在质量问题的，签收后24小时内举证可申请退换

5. 附则
本规则为《七天无理由退货规则》的补充条款，冲突之处以本规则为准。
