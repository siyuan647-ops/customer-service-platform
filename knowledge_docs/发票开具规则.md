【基础信息】
- 政策标题：发票开具规则
- 生效日期：2026-01-01
- 失效日期：-
- 适用商品分类：全品类

1. 开票类型
1.1 增值税普通电子发票：默认开具，可用于报销、售后
1.2 增值税专用发票：企业用户可申请，需提供开票信息

2. 开票内容
2.1 按实际购买商品名称、规格、金额开具
2.2 不支持变更品名、虚开金额
2.3 订单含运费的，运费可合并开具或单独开具

3. 申请方式
3.1 下单时勾选“需要发票”，填写开票信息
3.2 订单完成后30天内，可在订单详情页补开发票
3.3 电子发票开具后发送至预留邮箱，可自行下载打印

4. 开票时效
4.1 普通电子发票：订单完成后48小时内开具
4.2 增值税专用发票：申请后5-7个工作日开具并寄出

5. 换开与红冲
5.1 发票信息有误，30天内可申请换开
5.2 发生退货退款，已开发票需红冲处理
5.3 换开发票需将原发票退回

6. 注意事项
6.1 一个订单对应一张发票，不支持拆分开票
6.2 优惠券、红包抵扣部分不开具发票
6.3 预售商品在尾款支付完成后开具全额发票

7. 常见问题
Q：电子发票和纸质发票效力一样吗？
A：一样，电子发票是税务局认可的有效凭证，可用于报销、保修。
