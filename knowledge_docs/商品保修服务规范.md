【基础信息】
- 政策标题：商品保修服务规范
- 生效日期：2026-02-20
- 失效日期：-
- 适用商品分类：数码电器、家居家电

1. 保修范围
1.1 商品在正常使用情况下出现的质量故障、功能异常
1.2 原厂配件、元器件非人为损坏
1.3 保修期限内的非人为故障

2. 保修期限
2.1 数码电子产品：全国联保1年，详情以商品说明为准
2.2 大小家电：整机保修1-3年，主要部件保修3-5年
2.3 家居用品：质保3个月至1年不等
2.4 保修期自商品签收之日起计算

3. 保修流程
3.1 联系客服说明故障情况，提供订单号和故障照片/视频
3.2 客服判断是否符合保修条件
3.3 符合条件的，指引送修或寄修，或安排上门维修
3.4 维修完成后寄回或验收

4. 保修费用
4.1 保修期内非人为质量问题，免维修费、免配件费
4.2 寄修模式：商家承担寄回运费，消费者承担寄出运费
4.3 人为损坏、过保商品，收取配件费+维修费

5. 不予保修情形
5.1 人为损坏、进水、摔碰、私自拆卸改装
5.2 使用不当、未按说明书操作造成的故障
5.3 不可抗力（火灾、水灾、雷击等）造成的损坏
5.4 超过保修期限
5.5 无有效购买凭证

6. 常见问题
Q：保修需要发票吗？
A：有发票按发票日期计算保修期；无发票按订单签收日期计算。

Q：可以换新吗？
A：保修期内同一故障维修两次仍无法正常使用，可申请换新。
