【基础信息】
- 政策标题：质量问题退款处理规范
- 生效日期：2026-03-15
- 失效日期：-
- 适用商品分类：全品类

1. 政策概述
商品存在质量瑕疵、功能故障、描述不符等问题，消费者可申请质量问题退款、换货或部分退款，相关费用由商家承担。

2. 质量问题界定
2.1 商品存在破损、变形、污渍、漏液等外观瑕疵
2.2 商品功能故障、无法正常使用、参数与描述不符
2.3 商品缺少配件、发错货、发错款式规格
2.4 商品存在过期、变质、假冒伪劣等合规问题

3. 举证要求
3.1 需在签收后48小时内提交申请并举证
3.2 举证材料：商品问题清晰照片/视频、快递面单照片、包装照片
3.3 数码电器类功能故障，需提供故障演示视频

4. 处理方式
4.1 全额退款：商品质量问题严重，无法使用，消费者退回商品后全额退款
4.2 部分退款：商品存在轻微瑕疵，不影响核心功能，消费者同意保留的，按比例退款
4.3 换货：消费者更换同款商品，商家承担往返运费

5. 费用与时效
5.1 质量问题退货运费由商家承担，消费者先行垫付后凭运费凭证报销
5.2 退款审核时效：24小时内完成核验
5.3 退款到账时效：核验通过后48小时内发起退款

6. 不支持情形
6.1 人为损坏、使用不当、自行维修造成的故障
6.2 超出举证时效（签收超过48小时）
6.3 商品正常磨损、色差、个人感官不喜欢等非质量问题

7. 常见问题
Q：我已经用了几天才发现质量问题，可以申请吗？
A：商品本身质量问题在质保期内均可申请；签收48小时内申请可直接走质量问题流程，超出时效需走保修流程。

Q：运费怎么报销？
A：您先垫付运费并保留快递面单和支付凭证，退款完成后联系客服报销，最高报销首重标准运费。
