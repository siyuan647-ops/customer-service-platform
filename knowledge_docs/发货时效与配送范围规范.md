【基础信息】
- 政策标题：发货时效与配送范围规范
- 生效日期：2026-01-15
- 失效日期：-
- 适用商品分类：全品类

1. 发货时效标准
1.1 普通商品：当日16:00前付款的订单，当日发货；16:00后付款的订单，次日发货
1.2 预售商品：按商品详情页标注的发货时间发货
1.3 大促期间（618、双11等）：付款后72小时内发货
1.4 定制、大件商品：按约定周期发货，详情页另行说明

2. 配送方式与承运商
2.1 普通商品：默认快递，系统自动匹配承运商
2.2 大件商品：物流配送，送货上门或自提，以商品说明为准
2.3 生鲜商品：冷链配送，全程温控

3. 配送范围
3.1 中国大陆地区（除港澳台及偏远地区）均可配送
3.2 偏远地区（新疆、西藏、青海、内蒙古部分区域）需补运费差价，或仅支持邮政配送
3.3 港澳台及海外地区暂不支持配送

4. 配送时效参考
4.1 江浙沪皖：发货后1-2天送达
4.2 华东、华南、华北主要城市：发货后2-3天送达
4.3 西南、西北、东北主要城市：发货后3-5天送达
4.4 偏远地区及乡镇：发货后5-7天送达

5. 截单与改址
5.1 每日16:00为当日截单时间，截单后订单次日发货
5.2 订单未发货前可修改收货地址，发货后无法修改
5.3 改址仅支持同一城市内变更，跨城市无法改址

6. 常见问题
Q：为什么我的订单超过时间还没发货？
A：大促、预售商品按约定时效发货；如遇库存不足、天气管制等特殊情况，客服会提前联系您说明。

Q：可以指定快递吗？
A：暂不支持指定快递，系统会根据地址自动选择最优配送方式。
